# 親子リトミック教室「おとのは」体験レッスンLP

> **自主制作サンプルです。** ポートフォリオ用に作った架空の教室で、実在しません。

首すわり頃〜3歳の未就園児と保護者に向けた、親子リトミック教室の体験レッスン申込ページ（1ページ完結のLP）です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページの中身（文章と構造） |
| `style.css` | 見た目（色・レイアウト・装飾・レスポンシブ・アニメーション） |
| `script.js` | スクロールで要素をふわっと表示する処理 |

ビルドは不要です。`index.html` をブラウザで開くと表示されます。

## ページ構成

1. ファーストビュー（教室名・キャッチコピー・対象年齢・体験500円・申込ボタン）
2. こんなこと、ありませんか？（ターゲットの悩み5つ）
3. リトミックで、じわじわ育つ力（6つの力）
4. 非認知能力についてのコラム
5. ママにとっても、うれしいこと
6. 年齢別のクラス（0〜1歳／1〜2歳／2〜3歳）
7. 体験レッスン当日の流れ（45分のタイムライン）
8. 先生の紹介
9. 料金と開催概要（表）
10. よくあるご質問（6問）
11. 体験レッスンのお申し込み（ダミーフォーム・送信不可）
12. フッター

## 制作のポイント

- **外部ライブラリなし**：JavaScript は素の JS のみ。FAQ の開閉は HTML 標準の `<details>` / `<summary>` で実装
- **スマホ優先（モバイルファースト）**：スマホ用の指定を基本に書き、画面幅 768px 以上で PC 用に上書き。PC では最大幅 880px で中央寄せ
- **画像なし**：丸・波線・音符などの装飾は CSS（`radial-gradient` や疑似要素）で表現。写真が入る想定の場所は「写真イメージ」と書いた淡い色のボックス
- **スマホ用の固定申込ボタン**：画面下に固定し、申込セクションへページ内リンク。PC では非表示
- **読み進めやすさ**：セクションごとに背景色（白・淡い黄色・淡いミント）を交互に変更
- **色の管理**：`style.css` 冒頭の CSS 変数にまとめ、1か所の変更で全体に反映できるように
- **文章のトーン**：不安を煽らない・責めない・急かさない。効果は断定せず「土台づくり」と表現
- 架空の教室のため `noindex` を指定し、検索結果に出ないようにしています

## 動き（「楽しくてポップ、でも鬱陶しくない」）

| 動き | 実装 |
|---|---|
| スクロールで初めて画面に入った要素をふわっと表示（1回だけ。カードは0.08秒ずつ順番に） | `IntersectionObserver` + CSS アニメーション |
| 装飾の音符（ページ全体で5個）が6秒かけて上下に6pxだけ往復 | CSS アニメーション（ページ内でくり返す動きはこれだけ） |
| 「体験500円」のバッジを-3度傾けたステッカー風にし、表示時に1回だけ軽く弾む | CSS アニメーション |
| ボタンはホバーで1.03倍、押した瞬間に少し沈む（画面下の固定ボタンは押したときだけ） | CSS `transition` |
| カードはホバー時だけ2px浮いて影が濃くなる（PC表示のみ） | CSS `transition` |

- アニメーションは `transform` と `opacity` だけで実装（ブラウザが軽く処理できる2つ）
- OS で「動きを減らす」設定にしている人（`prefers-reduced-motion: reduce`）には、すべての動きを止めて最初から全部表示
- JavaScript が動かない環境でも、隠れたままにならず全部表示される作り

## 設定（すべて架空）

- 場所：岡崎市内（住所の記載なし）
- 対象：首すわり頃〜3歳の未就園児と保護者
- 体験レッスン：45分・500円（手ぶら・ベビーカーOK）
- 通常レッスン：月3回・月謝6,000円（目安）
